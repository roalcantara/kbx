Actions — one rule for the whole app (v3)

One component builds every action panel from a list. Below: the list view's panel for a command with links and for a bookmark, the detail view's panel, and the two submenus. Each panel's footer line shows what kb's footer would show.

The rule (Raycast's): the panel's first action is ↵ (primary), its second is ⌘↵ (secondary), by position, in every view. The footer shows the primary's name ↵ and Actions ⌘K. Other actions keep their own shortcut. Links… › appears only when the entry has links; each link row opens it with ↵. At most two levels: the root, then one submenu (Links… or More…). Shortcuts fire from the view wherever an action is listed.
