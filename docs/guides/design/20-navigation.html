Bookmarks, with and without a hero (template v3)

The same four slots for every entry: 1 Header [the row's icon] the title, one line, tags right · 2 Hero per type · 3 Quote the full description with the red bar · 4 Body the notes. For a bookmark the hero is its thumbnail when it has one (YouTube today; other sites once og:image lands), otherwise its URL as a link line, so the URL is always on screen.
