### A01 (K2). The filter's selected row scrolls out of sight behind the Search field

| Field            | Content                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Severity         | Major                                                                                                                                                                                                                                                                                                                                                                             |
| Status           | Confirmed (failing test)                                                                                                                                                                                                                                                                                                                                                          |
| Screen and state | Filter (⌘P), any page taller than the popover; also the action panel's root search, which lists More…, Refresh More…, Theme… and Links… under section labels                                                                                                                                                                                                                      |
| Steps            | ⌥K, ⌘P, ↓ repeatedly to the last tag                                                                                                                                                                                                                                                                                                                                              |
| Expected         | The selected row stays in view (Design Guides, "Lists, tables": the selection is always visible; spec 2026-10-27 D1 asks the same of the report; the earlier fix `scrolls_selected_panel_row_into_view_when_filter_overflows` intended it)                                                                                                                                        |
| Actual           | The row scrolls behind the Search field; at the last tag it ends 133 px below the visible rows (481.5 px vs 348.5 px), about five rows                                                                                                                                                                                                                                            |
| Evidence         | `audit_k2_keeps_the_filter_s_selected_row_in_view`. `search_view/panel.rs:173` calls `panel_scroll.scroll_to_item(self.panel_selected)` with a row index, but `ui/action_panel.rs:119-139` adds each section's label and the hairline between sections as children of the same `panel-rows` scroll container, so the child index lags by one per label and hairline above the row |
| Suggested fix    | Map the row index to its child index in `panel()` (or wrap each section's label with its first row, or give each row its own scroll target by id) and scroll to that                                                                                                                                                                                                              |
| Effort           | S                                                                                                                                                                                                                                                                                                                                                                                 |

| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
