The command card, with real commands

Each command as fmt-rs formats it (breaks at && || | and inside loops when the line is too wide), at the true widths: split ≈ 68 characters at 12 pt, 62 at 13 pt; detail ≈ 98 at 13 pt (compact window; the expanded window is wider still). A line still wider than the card wraps at spaces only, with a hanging indent so it never looks like a new command; ligatures off, so you see exactly what you copy. Colours as the bash grammar marks them: commands, -flags, 'strings', $vars and $(…), keywords, operators; plain values in text colour. The green number is the card's height.
