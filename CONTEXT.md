# Context

The domain words of this repository, each with where it lives. They are kb's words; code, specs and prompts use
them and no synonyms.

| Term              | Meaning                                                                                                                                                                                                                                                                     | Lives in                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Entry             | One knowledge node users can search and open: a YAML key under an entry type. Its id is `<rel path>#<type>#<key>`.                                                                                                                                                          | `crates/kb-domain/src/entry.rs`                                                                                                   |
| Entry type        | The top-level YAML key an entry sits under, or `skills` for a Skills record. The app shows five — Bookmarks, Cheat Sheets, Commands, Tasks, Skills (the catalog's `types`); the engine keeps every key.                                                                     | `crates/kb-domain/src/entry.rs`, `crates/kb-domain/src/skills.rs`; labels, icons and tints in `crates/kb-app/assets/catalog.toml` |
| Sources directory | Where source files are found, recursively: `sources_path` in `~/.config/kb/config.toml`, else `~/.config/kodexb/sources`.                                                                                                                                                   | `crates/kb-app/src/config.rs`                                                                                                     |
| Source file       | A `.yml` or `.yaml` file under the sources directory; the only source of truth, never written. A Skills entry's source file is its `SKILL.md`.                                                                                                                              | `crates/kb-domain/src/source.rs`                                                                                                  |
| Skills source     | The records of `skills ls --global --agent universal --json` (`skills_command` in `~/.config/kb/config.toml`, else `skills` found on `PATH` or in `/opt/homebrew/bin`, `/usr/local/bin`, `~/.local/bin`); each becomes a `skills` entry keyed `/<name>`.                    | `crates/kb-domain/src/skills.rs`, `crates/kb-app/src/command_path.rs`                                                             |
| Primary content   | What an entry's main action opens or copies: its `url`, `cmd`, `cheat` or `task` field, else its key.                                                                                                                                                                       | `crates/kb-domain/src/entry.rs`                                                                                                   |
| Tags              | An entry's `tags` (or `tag`) labels, lowercased. Filterable; not in the full-text index.                                                                                                                                                                                    | `crates/kb-domain/src/entry.rs`                                                                                                   |
| Index             | `kb.db`: `entries` (each row's `source`: `yaml` or `skills`), the `entries_fts` FTS5 table, `entry_tags`, in the app's own support directory; `PRAGMA user_version` migrates it.                                                                                            | `crates/kb-domain/src/sync.rs`, `crates/kb-domain/src/schema.sql`                                                                 |
| Index row         | The SQLite projection of one entry, including the pre-compiled notes Markdown.                                                                                                                                                                                              | `crates/kb-domain/src/row.rs`                                                                                                     |
| Notes             | An entry's documentation in whatever shape its source file used; compiled to Markdown at sync time. A `file://` note is replaced by that file's content.                                                                                                                    | `crates/kb-domain/src/markdown.rs`                                                                                                |
| Query             | The search text plus the filter and page window. Each word becomes an FTS5 prefix term; results are ordered by rank.                                                                                                                                                        | `crates/kb-domain/src/query.rs`                                                                                                   |
| Filter            | The entry types and tags a query is narrowed to: any selected type, and every selected tag.                                                                                                                                                                                 | `crates/kb-domain/src/search.rs`                                                                                                  |
| Sync              | The manual refresh of the index from its sources: all of them (Refresh, ⌘R), or one (Refresh YAML, Refresh Skills, under More… → Refresh More…). Each source is its own transaction; cancellable.                                                                           | `crates/kb-domain/src/sync.rs`, `crates/kb-domain/src/selection.rs`                                                               |
| Sync report       | What a sync says per source: for YAML, each source file's entries indexed, skipped, or why it failed; for Skills, entries indexed, why the command failed, or not configured, and its warnings. The report navigates like the list: → its pane, ↵ a row's detail (a place). | `crates/kb-domain/src/report.rs`                                                                                                  |
| Panel             | The floating window the hotkey opens; hidden on Esc or when it loses focus.                                                                                                                                                                                                 | `crates/kb-app/src/panel.rs`                                                                                                      |
| Place             | A screen on the navigation stack — the list, an entry's detail, a refresh, a report row's detail; its header names where back goes.                                                                                                                                         | `crates/kb-app/src/navigator.rs`                                                                                                  |
| Hotkey            | The global key combination that shows the panel: ⌥K.                                                                                                                                                                                                                        | `crates/kb-app/src/panel.rs`                                                                                                      |
| Action panel      | The ⌘K list of actions for the screen and the selected entry, search at the bottom: the root, Links… and More…                                                                                                                                                              | `crates/kb-app/src/ui/action_panel.rs`, `crates/kb-app/src/actions.rs`                                                            |
| Catalog           | `crates/kb-app/assets/catalog.toml`: the entry types, actions, each screen's keys and the messages kb shows.                                                                                                                                                                | `crates/kb-app/src/catalog.rs`, `crates/kb-app/assets/catalog.toml`                                                               |
| Design token      | A value in DESIGN.md's front matter: a colour, a type role, a radius, a spacing or a component size.                                                                                                                                                                        | `DESIGN.md` front matter, `crates/kb-app/src/ui/design.rs`                                                                        |
| Screen keys       | What ↵, ⌘↵ and ⇧⌘↵ (and Esc on the refresh screen) do on a screen; the catalog's `[screens.*]`.                                                                                                                                                                             | `crates/kb-app/assets/catalog.toml` `[screens.*]`                                                                                 |
| Status line       | The footer's left side on the list: `● Ready • N results`, `● Refreshing…`, `● No index`.                                                                                                                                                                                   | `crates/kb-app/src/ui/footer.rs`                                                                                                  |
| Command card      | A command in JetBrains Mono, broken at operators by fmt-rs, wrapped with a hanging indent, with a copy button.                                                                                                                                                              | `crates/kb-app/src/ui/command_card.rs`                                                                                            |
| Notice            | A message bottom right above the footer, through GPUI Kit's Notification; _Copied to clipboard_ is one.                                                                                                                                                                     | `crates/kb-app/src/ui/notice.rs`                                                                                                  |
| Colour palette    | The colour roles and accents of the active theme (kb-native by default); `palettes.json` keeps alternatives for comparison. Never just 'palette'.                                                                                                                           | `crates/kb-app/src/theme/scheme.rs` (`Palette`), `tools/design/palettes.json`                                                     |
| Theme             | A base24 (or base16) colour scheme file in `~/.config/kb/themes/` (kb seeds its eight); mapped onto kb's colour roles; picked from More… → Theme…, saved as `theme` in config.toml; `kb-native` by default.                                                                 | `crates/kb-app/src/theme.rs`, `crates/kb-app/assets/themes/`                                                                      |
| Tag image         | An SVG drawn in place of a `#tag` pill, in a fixed square, when the tag-images folder has `<tag>.svg` (`tag_images_path`, default `~/.config/kb/images`).                                                                                                                   | `crates/kb-app/src/tag_images.rs`                                                                                                 |
| Size toggle       | ⌘⇧F: the panel switches between compact (860 × 520) and expanded (85% of the display), keeping its centre.                                                                                                                                                                  | `crates/kb-app/src/window_size.rs`                                                                                                |
| Trace             | `kb --trace`: the show and keystroke latencies the app logs to stderr, each from the frame that draws the change to the one after it.                                                                                                                                       | `crates/kb-app/src/trace.rs`                                                                                                      |
| Package           | `kb.app`: the release binary in a bundle with no Dock icon, signed ad hoc by `mise run package`.                                                                                                                                                                            | `crates/kb-app/Cargo.toml` (`[package.metadata.packager]`)                                                                        |
| Editor            | The `editor` command template in `~/.config/kb/config.toml` (`zed {file}:{line}`) that Edit opens a file with, at a line when known; unset, the file's default app.                                                                                                         | `crates/kb-app/src/editor.rs`                                                                                                     |

## Experiment

| Term       | Meaning                                                                                                   | Lives in                                                                                   |
| ---------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| Corpus     | A set of source files a run measures: `sample` (committed), `private` and `private-10x` (local only).     | `tools/bench/fixtures/`, `tools/bench/ts/corpus.ts`                                        |
| Golden     | An output of the TypeScript engine the Rust engine must reproduce.                                        | `crates/kb-domain/tests/fixtures/sample-goldens/`, `tools/bench/fixtures/private-goldens/` |
| Tier       | A measurement depth: 1 engine, 2 footprint, 3 perceived latency.                                          | `docs/guides/methodology.md`                                                               |
| Result     | One run's JSON, in the shared schema, under `docs/guides/results/`.                                       | `tools/bench/ts/bench.ts`                                                                  |
| Parity row | One user-visible behaviour of the Raycast command and its status in the port.                             | `docs/guides/parity.md`                                                                    |
| Task       | One of the five scripted jobs whose keystrokes and time are compared on both apps (T1–T5).                | `docs/guides/parity.md`                                                                    |
| Probe      | A script that measures a running app from outside; `probe` is the CGEvent driver they share.              | `tools/bench/probes/`                                                                      |
| Report     | The generated comparison of both implementations against the success criteria.                            | `tools/bench/report`, `docs/guides/report.md`                                              |
| Findings   | The hand-written reading of the report: why a criterion failed or went unmeasured, and what would fix it. | `docs/guides/findings.md`                                                                  |
